# 音楽理論ノート

このノートはUdemyコース **Music Theory Comprehensive** を基にしています。

## 基本原則

- **常に自分の耳を信じること。** 心地よく聴こえるなら、それが正解です。
- **ルールは頻繁に破ってよい。** 音楽理論は規範（こうすべきという強制）ではなく、記述（現象の説明）です。

---

## 用語

- **変化記号 (Accidentals)**: 音高の変化を示す記号（シャープ $\sharp$、フラット $\flat$、ナチュラル $\natural$ など）。
- **音程 (Intervals)**: 2つの音の間の音高の距離。
  - **オクターブ (Octave)**: ある音と同じ音名を持つ次の音までの音程（例: Cから次のCまで）。_注: 中央のCはC4と表記されます。_
  - **半音 (Half step / Semitone)**: 西洋音楽において隣り合う2音間の最小の基本距離（例: CからC#、またはEからF）。
  - **全音 (Whole step / Tone)**: 半音2つ分の距離（例: CからD、またはEからF#）。

### 拍子記号 (Time Signatures)

拍子記号は分数のように表記されます。上の数字は1小節に拍が**いくつあるか**を示し、下の数字は**どの音符**が1拍を表すかを示します。

| 拍子記号        | 意味                                                                                |
| :-------------- | :---------------------------------------------------------------------------------- |
| **$4 \over 4$** | 1小節に4分音符が4つ（4分の4拍子 / コモンタイム）                                    |
| **$3 \over 4$** | 1小節に4分音符が3つ（4分の3拍子 / ワルツ）                                          |
| **$6 \over 8$** | 1小節に8分音符が6つ（複合拍子。通常、8分音符3つを1拍とする2拍子として感じられます） |

## 音階 (Scales)

### ダイアトニックとクロマティック

- **ダイアトニック (Diatonic / 全音階的)**: 音が特定の調（キー）の中に厳密に収まっている状態。
- **クロマティック (Chromatic / 半音階的)**: 特定の調に厳密に縛られず、12音すべてを活用する状態。

### 長音階 (The Major Scale)

メジャースケールは全音 (W) と半音 (H) の特定の並びに従います: **全 - 全 - 半 - 全 - 全 - 全 - 半 (W - W - H - W - W - W - H)**

**メジャースケールの例:**

| 調 (Key)      | 構成音                             |
| :------------ | :--------------------------------- |
| **Cメジャー** | C - D - E - F - G - A - B - C      |
| **Gメジャー** | G - A - B - C - D - E - F# - G     |
| **Dメジャー** | D - E - F# - G - A - B - C# - D    |
| **Aメジャー** | A - B - C# - D - E - F# - G# - A   |
| **Eメジャー** | E - F# - G# - A - B - C# - D# - E  |
| **Bメジャー** | B - C# - D# - E - F# - G# - A# - B |
| **Fメジャー** | F - G - A - Bb - C - D - E - F     |

### 主音・音級・階名 (Tonic, Scale Degrees, Solfege)

- **主音 (Tonic)**: スケールの最初と最後の音。スケール名はこの音に由来します（例: Cメジャーの主音はC）。
- **音級 (Scale Degrees)**: スケール内の音の番号順の位置（1度〜7度）（例: CメジャーにおけるGは第5音/5度）。
- **ソルフェージュ (Solfege / 階名唱法)**: 音を表すシラブル（ド・レ・ミ・ファ・ソ・ラ・シ・ド）。
  - **移動ド (Movable Do)**: 「ド」が常に現在のスケールの主音になります（第1音がド、第2音がレなど）。
  - **固定ド (Fixed Do)**: 調に関わらず「ド」は常にC、「レ」は常にDです。

### 音級の名称と機能 (Scale Degree Names)

スケールの各音度には伝統的な名称と特有の機能・傾向があります:

| 音度  | 名称                     | 傾向 / 機能                                                 |
| :---: | :----------------------- | :---------------------------------------------------------- |
| **1** | **主音 (Tonic)**         | 楽曲の拠点（ホームベース）。最も安定した音。                |
| **2** | **上主音 (Supertonic)**  | 主音へ下行解決する傾向がある。                              |
| **3** | **中音 (Mediant)**       | 主音へ下行解決する傾向がある。                              |
| **4** | **下属音 (Subdominant)** | 主音へ上行/下行、中音へ下行、あるいは属音へ上行解決できる。 |
| **5** | **属音 (Dominant)**      | 主音に向かう強い和声的引力を持つ。                          |
| **6** | **下中音 (Submediant)**  | 概ねニュートラルだが、主音へ上行解決することもある。        |
| **7** | **導音 (Leading Tone)**  | 主音へ上行して解決しようとする非常に強い引力を持つ。        |

## 調 (Keys)

### 調号からメジャーキーを見分けるコツ

- **シャープ系 ($\sharp$)**: 一番右（最後）のシャープの音から半音上の音がその調（キー）になります。_(注: その音が調号でシャープされている場合は、F#メジャーのようにシャープをつけて呼びます)_。
- **フラット系 ($\flat$)**: 右から2番目のフラットの音がその調（キー）になります。_(例外: フラットが1つの場合はFメジャー)_。
- **調号なし**: Cメジャー。

### 短調 (Minor Keys)

短調は長調と密接に関連しています。一般的なマイナースケールには3種類あります: 自然短音階 (Natural)、和声的短音階 (Harmonic)、旋律的短音階 (Melodic)。

#### 1. 自然短音階 (Natural Minor)

自然短音階を理解するには3つのアプローチがあります:

1. **平行調 (Relative Minor)**: メジャースケールの第6音が、同じ調号を共有する平行自然短音階の主音になります。
   - _例:_ Cメジャー (C D E F G A B C) $\rightarrow$ Aマイナー (A B C D E F G A)
2. **ステップパターン**: **全 - 半 - 全 - 全 - 半 - 全 - 全 (W - H - W - W - H - W - W)**
3. **同主調 (Parallel Minor)**: メジャースケールと同じ主音から始まり、第3音、第6音、第7音を半音下げたもの。
   - _例:_ Cメジャー (C D E F G A B C) $\rightarrow$ Cマイナー (C D Eb F G Ab Bb C)

#### 2. 和声的短音階 (Harmonic Minor)

- 自然短音階の第7音を半音上げます。
- これにより導音（主音の半音下の音）が生まれ、主音へのより強い解決感が得られます。

#### 3. 旋律的短音階 (Melodic Minor)

- *上行時*には、自然短音階の第6音と第7音を半音上げます。
- *下行時*には、自然短音階の形に戻します。

### 五度圏 (Circle of Fifths)

![Circle of fifths](https://github.com/jinyongnan810/music-theory/assets/29720903/70bc2579-d772-4f65-b409-a8cf964af9cb)

### マイナーキーの限界と解決策

- **問題点**: 自然短音階には導音がありません（主音の下が半音ではなく全音離れているため）。このため、マイナーの **v** コードからマイナーの **i** コードへの解決感が弱くなります。
- **解決策**: 実際には、調の第7音を半音上げて **v** コードをメジャーコードの **V** に変更することがよく行われます。これは **和声的短音階 (Harmonic Minor)** の響きを利用したものです。

## 和音・コード (Chords)

### 三和音 (Triads)

三和音（トライアド）は、3度音程で3つの音を積み重ねたコードです（三度堆積和声）。

- **第3音 (3rd)**: トライアドがメジャーかマイナーかを決定づけます。
- **第5音 (5th)**: メジャー・マイナートライアドの両方で基本的に同じ（完全5度）です。

| 和音の種類 (Quality)            | 構造                                 | 例 (Cルート) |
| :------------------------------ | :----------------------------------- | :----------- |
| **メジャー (Major)**            | ルート + 長3度 (全音2つ) + 完全5度   | C - E - G    |
| **マイナー (Minor)**            | ルート + 短3度 (全音1.5個) + 完全5度 | C - Eb - G   |
| **ディミニッシュ (Diminished)** | ルート + 短3度 + 減5度               | C - Eb - Gb  |
| **オーグメント (Augmented)**    | ルート + 長3度 + 増5度               | C - E - G#   |

_(注: オーグメント・トライアドはメジャースケール内には自然発生しません。)_

### ダイアトニック・コード進行 (Diatonic Chord Progressions)

メジャースケールにおいて、ダイアトニック三和音はスケール内の音だけを使って3度ずつ積み重ねて作られます。*すべての*メジャーキーにおけるコードクオリティのパターンは以下の通りです:
**Major - minor - minor - Major - Major - minor - diminished**

**ディグリーネーム分析 (例: Cメジャー):**
大文字はメジャー、小文字はマイナー、° はディミニッシュを表します。

|   数字   | コード  | 構成音    | クオリティ                        |
| :------: | :------ | :-------- | :-------------------------------- |
|  **I**   | C major | C - E - G | Major                             |
|  **ii**  | D minor | D - F - A | minor                             |
| **iii**  | E minor | E - G - B | minor                             |
|  **IV**  | F major | F - A - C | Major                             |
|  **V**   | G major | G - B - D | Major                             |
|  **vi**  | A minor | A - C - E | minor                             |
| **vii°** | B dim   | B - D - F | diminished (緊張感のあるマイナー) |

\*自然短音階（ナチュラルマイナーキー）では、三和音のパターンは **i - ii° - III - iv - v - VI - VII** に変化します。

### 転回形 (Inversions)

- ルート音（根音）が最低音（バス）ではない場合に転回形となります。
- コード進行において、よりスムーズで音楽的なベースラインの推移を作るために使われます。

### 7thコード (7th Chords)

7thコードは4和音（三和音 + 第7音）です。

- **メジャーセブンス (M7 / Major 7th)**: メジャートライアド + 長7度（オクターブの半音下）。
- **マイナーセブンス (m7 / Minor 7th)**: マイナートライアド + 短7度（オクターブの全音下）。
- **ドミナントセブンス (7 / Dominant 7th)**: メジャートライアド + 短7度（ブルースやジャズで多用され、強い緊張感を生む）。

### サスペンディッド・コード (Suspended Chords)

サスペンディッド（sus）コードは、3度の音を2度または4度の音に置き換えたもので、未解決で浮遊感のある響きを作ります。

- **sus2**: ルート - 2度 - 5度（例: C - D - G）
- **sus4**: ルート - 4度 - 5度（例: C - F - G）
