# 配列、動的配列、文字列（Arrays / dynamic arrays / strings）

## 静的配列 (Array)

配列は、メモリ内の連続したブロックに要素を格納するデータ構造です。

各要素にはインデックス（添字）が割り振られます。

基本となる考え方:

> コンピュータが配列の先頭メモリアドレスを把握しており、各要素のサイズが均一であれば、任意のインデックスの位置へ直接ジャンプ（ランダムアクセス）できます。

## 動的配列 (Dynamic arrays)

現代の多くのプログラミング言語（Python の `list`、JavaScript の `Array`、Go のスライス、Rust の `Vec` など）で使われる配列は、サイズを伸縮できる「動的配列」です。

しかし、内部的には通常の配列と同様にメモリ上に連続して格納されています。

配列の末尾に十分な空き容量（キャパシティ）がある場合、末尾への要素追加（Append）は高速に行われ、計算量は $O(1)$ です。

しかし、確保されたメモリ領域がいっぱいになった場合、以下の処理が発生します:

1. より大きな新しいメモリブロックを確保する
2. 古いブロックから新しいブロックへ全要素をコピーする
3. 新しい要素を追加する

この再割り当てが発生した1回の操作は $O(n)$ の計算量になります。

ただし、メモリの再確保は毎回発生するわけではないため、多数の操作にわたって平均すると、末尾追加の計算量は依然として以下のようになります:

$$
\text{ならし計算量（Amortized append）} = O(1)
$$

ならし計算量（Amortized）とは:

> 一部の操作はコストが高いものの、多数の操作全体に分散させると、1回あたりの平均コストは非常に低くなるという考え方です。

### 文字列 (Strings)

文字列は本質的に文字の配列ですが、多くの言語でイミュータブル（不変）として扱われます。
そのため、文字列の連結を行うたびにすべての文字が新しいメモリにコピーされます。

```py
result = ""

for word in words:
    result += word
```

このようなコードは、$n$ 回の連結ごとに文字全体のコピーが繰り返されるため、$O(n^2)$ の高コストになる可能性があります。以下のようにリストに集めてから最後に結合する方が効率的です:

```py
parts = []

for word in words:
    parts.append(word)

result = "".join(parts)
```

## 代表的な計算量

| 操作内容                               |      一般的な計算量 | 理由                                               |
| -------------------------------------- | ------------------: | -------------------------------------------------- |
| インデックスによる配列要素へのアクセス |              `O(1)` | 先頭アドレスからの直接ジャンプ                     |
| インデックスによる配列要素の書き換え   |              `O(1)` | 直接ジャンプ                                       |
| 動的配列の末尾への要素追加 (Append)    |       ならし `O(1)` | 通常は容量に空きがあるため                         |
| 先頭への要素挿入                       |              `O(n)` | 後続の全要素を1つずつ右にシフトする必要がある      |
| 中間への要素挿入                       |              `O(n)` | 挿入位置以降の要素をシフトする必要がある           |
| 先頭からの要素削除                     |              `O(n)` | 残りの全要素を1つずつ左にシフトする必要がある      |
| 末尾からの要素削除                     |              `O(1)` | シフト処理が不要                                   |
| `k` 個の要素のスライス取得             |              `O(k)` | `k` 個の要素をコピーするため                       |
| 文字列の線形走査                       |              `O(n)` | 各文字を順番にチェックするため                     |
| ループ内での文字列の連続結合 (`+=`)    | 多くの場合 `O(n^2)` | 毎回新しい文字列オブジェクトへコピーが発生するため |
| `join` による文字列構築                |              `O(n)` | 最終結合時に1度だけメモリコピーを行うため          |
