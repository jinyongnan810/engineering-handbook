# 条件付き確率とベイズの定理（Conditional probability and Bayes’ rule）

## 条件付き確率 (Conditional probability)

条件付き確率は以下の問いに答えるものです:

> 「事象 B が既に起きたという条件下で、事象 A が発生する確率はいくらか？」

$$
P(A \mid B)=\frac{P(A\cap B)}{P(B)}
$$

## 事前確率 / 基準率 (Base rate)

基準率（ベースレート / 事前確率）とは、新たな証拠や検査結果を得る前の、母集団における元の発生確率です。

例:

> 全人口の 1% がある病気に罹患している。

この 1% が基準率です。

対象となる状態が非常に稀（低頻度）である場合、どれほど検査精度が高くても大量の「偽陽性（空振り）」が発生するため、基準率を考慮することが極めて重要になります。
例えば、10,000人のうち 100人に1人（1%）しか病気にかかっていない場合:

- 実際に罹患している人: 100人
- 罹患していない健康な人: 9,900人

偽陽性率がわずか数パーセントであっても、9,900人の健康な人に対して誤検知が多数発生してしまいます。

## 偽陽性と偽陰性 (False positives and false negatives)

| 用語                        | 意味                                                         |
| --------------------------- | ------------------------------------------------------------ |
| **真陽性 (True positive)**  | アラートが「陽性」と判定し、現実も実際にそうである           |
| **偽陽性 (False positive)** | アラートが「陽性」と判定したが、現実はそうではない（誤検知） |
| **真陰性 (True negative)**  | アラートが「陰性」と判定し、現実もそうではない（正常検知）   |
| **偽陰性 (False negative)** | アラートが「陰性」と判定したが、現実は陽性である（見逃し）   |

医療検査における例:

| 検査結果            | 現実の病気の状態   |
| ------------------- | ------------------ |
| 陽性判定 (Positive) | 病気の存在を示唆   |
| 陰性判定 (Negative) | 病気の非存在を示唆 |

## ベイズの定理 (Bayes’ rule)

ベイズの定理は、新たな証拠（エビデンス）を観測した後に確率（事後確率）を更新するための公式です。

$$
P(A \mid B)=\frac{P(B \mid A)P(A)}{P(B)}
$$

日常的な表現に直すと:

$$
P(\text{本当に問題がある} \mid \text{陽性アラートが発生})
=
\frac{
P(\text{陽性アラート} \mid \text{本当に問題がある})
P(\text{本当に問題がある})
}{
P(\text{陽性アラート})
}
$$

これは以下の問いに答えるものです:

> 「陽性アラートを受け取った後、実際に問題が存在する確率はどれくらいか？」

## ベイズの定理の具体例

ある病気が非常に稀であるとします。
前提条件:

- 罹患率は 1%（基準率）
- 罹患している場合、検査は 99% の確率で陽性となる（感度 / 真陽性率）
- 罹患していない場合、検査は 5% の確率で誤って陽性となる（偽陽性率）

直感的に理解するために 10,000 人の集団で考えます。

### ステップ 1: 基準率から人数を分ける

10,000 人のうち 1% が罹患している:

| グループ       |    人数 |
| -------------- | ------: |
| 罹患している   |   100人 |
| 罹患していない | 9,900人 |

### ステップ 2: 真陽性率を適用

検査は罹患している人の 99% を正しく陽性と判定するため、$100 \times 0.99 = 99$ 人が陽性になります。

### ステップ 3: 偽陽性率を適用

健康な人の 5% が誤って陽性と判定されるため、$9,900 \times 0.05 = 495$ 人が誤判定で陽性になります。

### ステップ 4: 陽性判定の合計を計算

| 内訳                       |  人数 |
| -------------------------- | ----: |
| 罹患しており陽性（真陽性） |  99人 |
| 健康だが陽性（偽陽性）     | 495人 |
| 陽性の総数                 | 594人 |

したがって、陽性判定が出た場合に実際に病気にかかっている確率は:

$$
P(\text{罹患} \mid \text{陽性})
=
\frac{99}{594}
\approx 0.167 \quad (16.7\%)
$$

検査自体の真陽性率が 99% と高精度であっても、陽性結果が出たときに本当に罹患している確率は約 16.7% にすぎません。病気自体が稀であるため、偽陽性の数が真陽性の数を圧倒してしまうからです。

## なぜ基準率が重要なのか（基準率の無視の誤謬）

よくある誤解は次のように考えてしまうことです:

> 「検査の精度が 99% なのだから、陽性が出たら 99% の確率で病気にかかっているはずだ。」

これは基準率を無視しています。
本当に問うべき問いは:

> 「陽性判定を受けたすべての人の中で、本当に陽性である人は何人いるか？」

この例では:

- 真陽性: 99人
- 偽陽性: 495人
- 陽性判定 594件のうち、本当の陽性はわずか 99件のみ

このように、基準率は結果の解釈を根本から変えてしまいます。

## 陽性アラートの解釈法

システムアラートや検知結果を解釈する際は、常に以下を自問します:

> 本当の問題はどれくらいの頻度で発生するか？

これが **基準率 (Base rate)** です。

> アラートは本当の問題をどれくらいの割合で正しく捉えられるか？

これが **感度 (Sensitivity) / 真陽性率** です。

> アラートはどれくらいの頻度で誤検知するか？

これが **偽陽性率 (False positive rate)** です。

> すべてのアラートのうち、本物の問題は何割あるか？

これが実務上最も重要な **適合率 (Precision) / 陽性的中率** です。

## メンタルモデル

ベイズの定理の本質は以下の通りです:

> 新しい信念（事後確率） = 元の信念（事前確率） $\times$ 証拠の強さ（尤度）

構成要素:

- 元の信念 = 基準率（事前確率）
- 証拠の強さ = 証拠がどれだけ強く対象を指し示しているか
- 新しい信念 = 証拠を見た後の更新された確率

陽性アラートは「最終的な結論」ではありません。事前確率を更新するための「1つの証拠」です。
