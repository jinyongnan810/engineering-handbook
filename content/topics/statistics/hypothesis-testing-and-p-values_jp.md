# 仮説検定と p 値（Hypothesis Testing and p-values）

## 1. 全体像

仮説検定は、次のような疑問に答えるための統計的手法です:

> 「この結果は本物（有意な差）なのか、それとも単なる偶然のノイズなのか？」

具体例:

- 新しいウェブサイトのデザインによって登録率は本当に向上したか？
- 新薬は本当に症状を軽減しているか？
- 2つのユーザーグループの間に本質的な違いはあるか？
- このコインは歪んでいる（不正である）か？

基本的なアプローチ:

> まず「何の変化も起きていない（差はない）」と仮定し、その仮定のもとで観測されたデータがどれほど起こり得ない（驚くべき）ものかを検証する。

---

## 2. 帰無仮説 (Null Hypothesis)

**帰無仮説**（通常 $H_0$ と表記）は、検証の基準となるデフォルトの前提条件です。

通常、以下のように設定されます:

> 「真の効果はない」「真の差異はない」「関係性はない」

| 検証したい疑問                         | 帰無仮説 ($H_0$)                         |
| -------------------------------------- | ---------------------------------------- |
| 新しいボタンはクリック数を増やしたか？ | 新しいボタンに効果はない                 |
| コインに偏りはあるか？                 | コインは公平（表裏の確率は等しい）である |
| 新薬はプラセボより効果的か？           | 新薬の効果はプラセボと同等である         |
| 2つのグループの平均値は異なるか？      | 2つのグループの真の平均値は等しい        |

数式での表現:

$$
H_0: \text{新デザインに効果はない}
$$

2グループの平均値を比較する場合:

$$
H_0: \mu_A = \mu_B
$$

ここで:

- $\mu_A$: グループ A の真の平均値
- $\mu_B$: グループ B の真の平均値

---

## 3. 対立仮説 (Alternative Hypothesis)

**対立仮説**（通常 $H_1$ または $H_a$ と表記）は、研究者がデータを集めて主張したい本命の仮説です。

以下を主張します:

> 「効果が存在する」「差異が存在する」「関係性がある」

| 検証したい疑問                         | 対立仮説 ($H_1$)                     |
| -------------------------------------- | ------------------------------------ |
| 新しいボタンはクリック数を増やしたか？ | 新しいボタンはクリック数を増加させる |
| コインに偏りはあるか？                 | コインは公平ではない                 |
| 新薬はプラセボより効果的か？           | 新薬はプラセボより優れている         |
| 2つのグループの平均値は異なるか？      | 2つのグループの真の平均値は異なる    |

数式での表現:

$$
H_1: \mu_A \neq \mu_B
$$

これは **両側検定 (Two-sided test)** です。どちらの方向（増加または減少）であっても差異があるかを検証します。

一方、**片側検定 (One-sided test)** は特定の方向のみを検証します:

$$
H_1: \mu_B > \mu_A
$$

例:

> 新デザインのコンバージョン率は旧デザインよりも高い。

---

### 簡単な例

あるウェブサイトの現在のコンバージョン率が 10% だとします。
新デザインをテストした結果:

- 旧デザイン: 10%
- 新デザインのサンプル: 12%

問い:

> 新デザインによって本当に改善されたのか？ それとも単なる偶然のばらつきか？

仮説の設定:

$$
H_0: \text{新デザインのコンバージョン率は旧デザインと同じである}
$$

$$
H_1: \text{新デザインのコンバージョン率は旧デザインと異なる}
$$

この上で、p 値を計算して判断します。

---

## 4. p 値の直感的理解 (P-value Intuition)

**p 値 (p-value)** は以下の問いに答える確率です:

> 「もし帰無仮説が真であるとしたら、今回観測された結果（またはそれ以上に極端な結果）が得られる確率はどれくらい珍しいか？」

正確な定義:

> 帰無仮説が正しいと仮定したとき、実際に観測されたデータと同等かそれ以上に極端な結果が得られる確率。

### 重要な注意点

p 値は **「帰無仮説が正しい確率」ではありません**。

誤った解釈:

> 「p = 0.03 なので、帰無仮説が正しい確率は 3% である。」（誤り）

正しい解釈:

> 「もし帰無仮説が正しいとしたら、これほど極端なデータが得られる確率は 3% である。」（正解）

---

### 具体例

A/B テストを実行し、以下の結果が得られたとします:

$$
p = 0.03
$$

日常的な解釈:

> 新デザインに実際には何の効果もないと仮定した場合、偶然の偏りだけでこれほど大きな差（またはそれ以上の差）が生じる確率は約 3% である。

これはかなり珍しい（偶然とは考えにくい）現象であるため、帰無仮説を棄却して「効果がある」と判断します。

### p 値の計算の仕組み

**p 値は、観測された結果を「帰無仮説が真である場合に期待される確率分布」と比較することで計算されます**。

一般的な手順:

1. 帰無仮説が真であると仮定する。
2. 観測データから検定統計量（$t$ 値、カイ二乗値など）を計算する。
3. 「帰無仮説の分布のもとで、この検定統計量と同等以上に極端な値が出る確率はいくらか？」を求める。
4. その確率が p 値となる。

---

#### コイン投げの例

帰無仮説:

$$
H_0: \text{このコインは公平である (表が出る確率 } p = 0.5)
$$

コインを 10回投げたところ、9回表が出ました。

問い:

> コインが完全に公平である場合、10回中 9回以上表が出る確率はいくらか？

二項分布の確率計算式:

$$
P(X = k) = {n \choose k}p^k(1-p)^{n-k}
$$

9回表が出る確率:

$$
P(X = 9) = {10 \choose 9}(0.5)^9(0.5)^1 = 0.009765625
$$

10回表が出る確率:

$$
P(X = 10) = {10 \choose 10}(0.5)^{10} = 0.0009765625
$$

「9回以上表が出る」片側 p 値:

$$
P(X \geq 9) = P(X=9) + P(X=10) = 0.0107421875 \approx 0.0107 \quad (1.07\%)
$$

解釈:

> コインが公平である場合、10回中9回以上表が出るのは約 1.07% の頻度でしか起きない。

非常に小さな確率であるため、公平という前提は疑わしいと判断できます。

---

#### 代表的な検定手法と統計量

| 検証シナリオ             | 代表的な検定手法               | 検定統計量            |
| ------------------------ | ------------------------------ | --------------------- |
| コイン投げ / 割合の比較  | 二項検定 (Binomial test)       | 成功回数              |
| 2群の平均値の比較        | $t$ 検定 (t-test)              | $t$ 統計量            |
| カテゴリ度数・クロス集計 | カイ二乗検定 (Chi-square test) | $\chi^2$ 統計量       |
| 回帰係数の有意性         | $t$ 検定 / $F$ 検定            | $t$ または $F$ 統計量 |

論理の骨格はすべて共通です:

$$
p\text{ 値} = P(\text{観測データと同等以上に極端な結果} \mid H_0 \text{ が真})
$$

### 片側検定 vs 両側検定の p 値

「コインが不正かどうか」を検証する場合、表が極端に多い場合だけでなく、裏が極端に多い（表が1回以下）場合も同様に疑わしくなります。

両側検定の p 値:

$$
P(X \geq 9) + P(X \leq 1) = 0.0107 + 0.0107 = 0.0215
$$

| 検定タイプ |   p 値 |
| ---------- | -----: |
| 片側検定   | 0.0107 |
| 両側検定   | 0.0215 |

---

### Python による二項検定の実装

```python
from scipy.stats import binomtest

# 10回中9回表の片側検定
result = binomtest(k=9, n=10, p=0.5, alternative="greater")
print(result.pvalue)
# 0.0107421875

# 両側検定
result_two_sided = binomtest(k=9, n=10, p=0.5, alternative="two-sided")
print(result_two_sided.pvalue)
# 0.021484375
```

## 5. 有意水準 (Significance Level: $\alpha$)

検定を行う前に、判定のしきい値となる **有意水準 ($\alpha$)** をあらかじめ設定します。

一般的には $\alpha = 0.05$（5%）が用いられます。

判定基準:

| 結果            | 判定                                                 |
| --------------- | ---------------------------------------------------- |
| $p \leq \alpha$ | 帰無仮説を棄却する（統計的に有意な差がある）         |
| $p > \alpha$    | 帰無仮説を棄却しない（統計的に有意な差とは言えない） |

例:

|  p 値 | $\alpha$ | 判定                             |
| ----: | -------: | -------------------------------- |
|  0.03 |     0.05 | 統計的に有意                     |
|  0.12 |     0.05 | 統計的に有意ではない             |
| 0.049 |     0.05 | 統計的に有意（ギリギリ）         |
| 0.051 |     0.05 | 統計的に有意ではない（ギリギリ） |

※ $0.049$ と $0.051$ の実質的な違いはごく僅かです。しきい値は絶対的な真理ではなく、合意された慣習であることに注意が必要です。

---

## 6. 第1種の過誤 (Type I Error)

**第1種の過誤** は「偽陽性（あわてものの誤り）」です。

> 実際には帰無仮説が真である（効果がない）のに、誤って帰無仮説を棄却してしまうこと。

日常的な表現:

> 「本当は何の効果もないのに、効果があると誤認してしまうこと。」

例:
まったく効果のない薬を「効果がある」と誤判定する。効果のないデザインを「改善した」と誤認する。

第1種の過誤の発生確率は有意水準 $\alpha$ によって直接制御されます:

$$
\alpha = P(\text{第1種の過誤})
$$

$\alpha = 0.05$ に設定した場合、5% の偽陽性リスクを許容していることになります。

---

## 7. 第2種の過誤 (Type II Error)

**第2種の過誤** は「偽陰性（ぼんやりものの誤り）」です。

> 実際には対立仮説が真である（効果が存在する）のに、帰無仮説を棄却し損ねること。

日常的な表現:

> 「本当は効果があるのに、検定で見逃してしまうこと。」

例:
実際に効果がある新薬を「有意差なし」と判定してしまう。サンプルサイズが小さすぎて改善効果を証明できない。

第2種の過誤の確率は $\beta$ と表記されます:

$$
\beta = P(\text{第2種の過誤})
$$

第2種の過誤の逆（裏返し）が **検出力 (Statistical Power)** です:

$$
\text{検出力 (Power)} = 1 - \beta
$$

検出力とは、「効果が存在するときに、正しくそれを検出できる確率」を意味します。

---

## 8. 第1種と第2種の過誤のまとめ

| 概念               | 意味                   | 例                           |
| ------------------ | ---------------------- | ---------------------------- |
| **第1種の過誤**    | 偽陽性                 | 役に立たない薬を効くと信じる |
| **第2種の過誤**    | 偽陰性                 | 有効な薬の効果を見逃す       |
| $\alpha$           | 第1種の過誤の確率      | 一般に 0.05                  |
| $\beta$            | 第2種の過誤の確率      | サンプルサイズや効果量に依存 |
| **検出力 (Power)** | 真の効果を検出する確率 | $1 - \beta$                  |

| 検定の判断         | 現実の真実: 効果なし     | 現実の真実: 効果あり     |
| ------------------ | ------------------------ | ------------------------ |
| **効果ありと判断** | **第1種の過誤 (偽陽性)** | 正しい判断               |
| **差なしと判断**   | 正しい判断               | **第2種の過誤 (偽陰性)** |

---

## 9. 統計的有意性 vs 実用的な重要性

これは実務において極めて重要な区別です。

ある結果が **「統計的に有意 (Statistically Significant)」** であっても、**「実用的に重要 (Practically Meaningful)」** であるとは限りません。

### 統計的有意性

> 帰無仮説のもとで、その結果が偶然のノイズだけで生じたとは考えにくいこと。

### 実用的な重要性

> その効果の大きさが、ビジネスや現実世界で意味を持つほど十分に大きいこと。

例:
新デザインによってコンバージョン率が $10.000\% \rightarrow 10.001\%$ に向上したとします。
サンプル数が数億件あれば、この $0.001\%$ の差でも統計的に有意（$p < 0.001$）になります。
しかし、開発・保守コストやデザイン変更に伴うリスクに見合う実用的な価値があるとは言えません。常に「この差はビジネス上重要か？」を問う必要があります。

## 10. A/B テスト結果の読み解き方

購入手続きページの A/B テスト例:

| 指標             | 旧ページ | 新ページ |
| ---------------- | -------: | -------: |
| コンバージョン率 |    10.0% |    10.4% |
| p 値             |          |     0.03 |

$p = 0.03 < 0.05$ であるため統計的に有意ですが、以下の点も批判的に検証する必要があります:

1. 0.4 ポイントの改善はビジネス上の投資対効果に見合うか？
2. サンプルサイズは十分かつ偏りがないか？
3. ランダム化は正しく行われていたか？
4. 計測タグの不具合やトラッキングバグはないか？
5. 事前に定義された主要評価指標（Primary Metric）だったか？
6. 同時に多数のテストを行っていないか（多重検定問題）？
7. 売上単価や継続率への悪影響はないか？

---

## 11. サンプルサイズと p 値の関係

サンプルサイズが大きくなるほど、微小な差でも容易に検出できるようになります。

- **小サンプル:** 偶然のばらつきが大きく、本物の効果があっても見逃しやすい（第2種の過誤のリスク増大）。
- **巨大サンプル:** 極めて微小な差でも有意になりやすいため、効果の大きさ（実用性）に注視する必要がある。

## 12. Python によるカイ二乗検定の実装例

```python
import numpy as np
from scipy.stats import chi2_contingency

# 旧デザイン
old_visitors = 1000
old_conversions = 100

# 新デザイン
new_visitors = 1000
new_conversions = 120

# 分割表の作成:
# 行 = 旧デザイン / 新デザイン
# 列 = コンバージョン / 非コンバージョン
table = np.array([
    [old_conversions, old_visitors - old_conversions],
    [new_conversions, new_visitors - new_conversions],
])

chi2, p_value, dof, expected = chi2_contingency(table)

print("p値:", p_value)

alpha = 0.05

if p_value < alpha:
    print("統計的に有意な差があります")
else:
    print("統計的に有意な差はありません")

# p値: 0.17451579008209808
# 統計的に有意な差はありません
```

## 13. 実験結果を批判的に読み解くチェックリスト

「有意差あり ($p < 0.05$)」という報告を見たときは、以下を確認します:

1. **帰無仮説は明確に定義されているか？**
2. **対立仮説は両側か片側か？**
3. **効果量（実際の差の大きさ）はどれくらいか？**
4. **サンプルサイズは適切か？**
5. **ランダム化は適切か（交絡因子はないか）？**
6. **多重検定の補正はされているか？**
7. **指標は実験前に決定されていたか（p ハッキングの防止）？**

---

## 14. まとめ

仮説検定の標準的な流れ:

1. 帰無仮説 $H_0$ を設定する
2. 対立仮説 $H_1$ を設定する
3. データを収集する
4. 検定統計量と p 値を計算する
5. p 値を有意水準 $\alpha$ と比較する
6. $H_0$ を棄却するか判断する
7. その効果が実用的に価値があるかを確認する

本質的な考え方:

> p 値は「帰無仮説が真である場合に、観測データがどれほど珍しいか」を示す指標です。帰無仮説の真偽そのものの確率を示すものではありません。
