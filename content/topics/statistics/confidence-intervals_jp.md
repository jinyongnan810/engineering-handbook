# 信頼区間（Confidence intervals）

**信頼区間 (Confidence Interval / CI)** は、未知の母集団パラメータ（真の平均値や割合など）に対して、単一の数値を推測する代わりに、妥当と考えられる値の範囲（区間）を提示する統計的推定ツールです。

---

## 1. 点推定 vs 区間推定

- **点推定 (Point Estimate):** サンプルデータから母集団のパラメータを推測するために計算された単一の数値。例えば、100人を調査して平均睡眠時間が **7.2時間** だった場合、7.2 が点推定値になります。
- **区間推定 (Interval Estimate):** サンプルデータから導出される、真の母集団パラメータを含んでいる可能性が高い値の範囲。例えば、「平均睡眠時間は **6.8時間から7.6時間の間** にある」といった表現です。

**標本誤差 (Sampling error)**（誰が調査対象に選ばれたかという偶然のばらつき）があるため、点推定値が真の値と寸分狂わず完全に一致することはほぼあり得ません。

「平均睡眠時間は*きっかり* 7.2時間である」と断言することは絶対的な確実性を装うことになり、誤解を招きます。別のサンプルを抽出した場合にその推定値がどれほど変動し得るかについての情報が全く含まれていないためです。

区間推定はこの現実を受け入れ、バッファゾーン（不確実性の幅）を明示するため、より誠実で完全な統計情報を提供します。

---

## 2. 不確実性の範囲と信頼水準

信頼区間には通常、**95% 信頼区間** のようにパーセンテージ（信頼水準）が付随します。

- **その意味:** 実験や調査をまったく同じ条件で100回繰り返し、得られた新しいサンプルごとに区間を再計算した場合、100個の区間のうちおよそ95個が真の母集団平均を含んでいることを意味します。
- **トレードオフ（区間の幅 vs 不確実性）:** 区間の幅は不確実性の大きさを表します。

### 区間が広いほど不確実性が高い

誰かの正確な年齢を推測する場合を考えてみてください:

- **「25歳から35歳の間」** と推測した場合、当たる確信度は高いですが、範囲が広すぎて正確な年齢についての不確実性は高くなります。
- **「29歳から31歳の間」** と推測した場合、非常に精度（精密さ）は高いですが、外れるリスクはずっと高くなります。

---

## 3. 区間の幅とサンプルサイズ

許容誤差（マージン・オブ・エラー、区間の幅を決める値）の計算式では、標準偏差をサンプルサイズ（$n$）の平方根で割ります:

$$\text{許容誤差 (Margin of Error)} \propto \frac{1}{\sqrt{n}}$$

- **サンプルサイズが小さい場合 ($n$):** ばらつきが大きい。1〜2個の特異なデータポイントが結果を歪める可能性があります。真の値を確実に捉えるために、区間は **より広く** なります。
- **サンプルサイズが大きい場合 ($n$):** 大数の法則が働きます。個々のばらつきが相殺され、真の姿がより明確になります。区間は **より狭く**、精密になります。

---

## 4. 指標の解釈と具体例

$n = 30$ 人の学生のテスト点数のサンプルデータがあると仮定します。

全学生（母集団）の平均点について、2つの異なる **信頼水準**（$95\%$ と $99\%$）で **区間推定** を計算します。

### 計算式

小標本の場合や母標準偏差が未知の場合、学生の $t$ 分布を使用します:

$$\text{信頼区間} = \bar{x} \pm \left( t^* \times \frac{s}{\sqrt{n}} \right)$$

ここで:

- $\bar{x}$ = 標本平均（**点推定値**）
- $t^*$ = 信頼水準と自由度（$df = n - 1$）に基づく $t$ 分布の臨界値
- $s$ = 標本標準偏差
- $n$ = サンプルサイズ
- $\frac{s}{\sqrt{n}}$ = **標準誤差 (Standard Error / SE)**。標本平均が真の母平均からどれだけ変動し得るかの指標。
- $t^* \times \text{SE}$ = **許容誤差 (Margin of Error)**。**不確実性の範囲** を決定する値。

### Python による実装例

```python
import numpy as np
import scipy.stats as stats
import matplotlib.pyplot as plt

# 1. サンプルデータの生成 (学生30人のテスト点数)
np.random.seed(42)  # 毎回同じ乱数を生成
sample_data = np.random.normal(loc=75, scale=10, size=30)

# 2. 基本統計量の計算
sample_mean = np.mean(sample_data)
sample_size = len(sample_data)
sample_std = np.std(sample_data, ddof=1)  # ddof=1 で不偏標準偏差を計算
standard_error = sample_std / np.sqrt(sample_size)
df = sample_size - 1  # 自由度

print(f"標本平均 (点推定値): {sample_mean:.2f}")
print(f"標本標準偏差: {sample_std:.2f}")
print(f"サンプルサイズ (n): {sample_size}")
print(f"標準誤差: {standard_error:.2f}\n")

# 3. 95% 信頼区間の計算
confidence_95 = 0.95
t_critical_95 = stats.t.ppf(1 - (1 - confidence_95)/2, df)
margin_of_error_95 = t_critical_95 * standard_error
ci_95 = (sample_mean - margin_of_error_95, sample_mean + margin_of_error_95)

print(f"95% 信頼区間: [{ci_95[0]:.2f}, {ci_95[1]:.2f}]")
print(f"95% 許容誤差: {margin_of_error_95:.2f}\n")

# 4. 99% 信頼区間の計算
confidence_99 = 0.99
t_critical_99 = stats.t.ppf(1 - (1 - confidence_99)/2, df)
margin_of_error_99 = t_critical_99 * standard_error
ci_99 = (sample_mean - margin_of_error_99, sample_mean + margin_of_error_99)

print(f"99% 信頼区間: [{ci_99[0]:.2f}, {ci_99[1]:.2f}]")
print(f"99% 許容誤差: {margin_of_error_99:.2f}")

# 標本平均 (点推定値): 73.12
# 標本標準偏差: 9.00
# サンプルサイズ (n): 30
# 標準誤差: 1.64

# 95% 信頼区間: [69.76, 76.48]
# 95% 許容誤差: 3.36

# 99% 信頼区間: [68.59, 77.65]
# 99% 許容誤差: 4.53

# 5. 信頼区間の可視化
plt.errorbar(x=[95], y=[sample_mean], yerr=[margin_of_error_95],
             fmt='o', color='blue', capsize=8, elinewidth=3, label='95% 信頼区間')
plt.errorbar(x=[99], y=[sample_mean], yerr=[margin_of_error_99],
             fmt='o', color='red', capsize=8, elinewidth=3, label='99% 信頼区間')

plt.axhline(y=sample_mean, color='gray', linestyle='--', label=f'点推定値 ({sample_mean:.2f})')
plt.xlim(93, 101)
plt.xticks([95, 99], ['95% 信頼水準\n(狭い区間)', '99% 信頼水準\n(広い区間)'])
plt.ylabel('推定される平均テスト点数')
plt.title('信頼区間と不確実性範囲の比較')
plt.legend(loc='upper right')
plt.grid(axis='y', linestyle=':', alpha=0.6)
plt.tight_layout()
plt.savefig('confidence_intervals.png')
```

### 計算結果の解釈

スクリプトの出力結果:

- **標本平均（点推定値）:** $73.12$
- **標本標準偏差:** $9.00$
- **サンプルサイズ $n$:** $30$
- **標準誤差:** $1.64$

#### 95% 信頼水準の場合

- **許容誤差:** $3.36$
- **区間推定:** $[69.76, 76.48]$
- **意味:** 母集団全体の真の平均点が $69.76$ 点から $76.48$ 点の間にあると 95% 確信できます。真の平均がこの範囲外にある確率は 5% です。

#### 99% 信頼水準の場合

- **許容誤差:** $4.53$
- **区間推定:** $[68.59, 77.65]$
- **意味:** 母集団全体の真の平均点が $68.59$ 点から $77.65$ 点の間にあると 99% 確信できます（より確実に捉えるために区間が広がっています）。

### `ppf` 関数の解説: 逆引き関数

`scipy.stats` モジュールの `stats.t.ppf()` は **Percent Point Function（百分位点関数）** の略で、累積分布関数（CDF）の逆関数です。

分かりやすく言うと: **確率（曲線下の面積）を入力すると、対応する $t$ 値（臨界値）を出力します。**

信頼区間を計算する際、捉えたいデータの割合（95%など）を臨界値 $t^*$（平均から何標準誤差分離れるべきか）に変換する必要があります。`stats.t.ppf()` はこの逆引き計算を行います。

#### 引数の詳細

```python
t_critical_95 = stats.t.ppf(1 - (1 - 0.95)/2, df)
```

##### 1. 確率引数: `1 - (1 - confidence_95)/2`

信頼区間は **両側検定（両側区間）** であるため、5% の誤差（$\alpha = 0.05$）は左右両端の裾野（テイル）に等しく分割されます:

- 左端の裾野に 2.5%
- 右端の裾野に 2.5%

`stats.t.ppf()` は左から右への累積確率を計算するため、右側の境界点を求めるには、その点の左側に全体の 97.5%（中央の 95% + 左端の 2.5%）が存在する点（$0.975$）を指定します:

- $(1 - 0.95) / 2 = 0.025$（片側の裾野の面積）
- $1 - 0.025 = 0.975$（目標の $t$ スコアの左側全体の累積面積）

##### 2. 自由度引数 (`df`)

$t$ 分布の形状はサンプルサイズによって変化します。

- 自由度 `df` は $n - 1$（サンプルサイズから 1 を引いた値）として計算されます。
- `df` を渡すことで、特定のサンプルサイズに応じた正確な $t$ 曲線から臨界値が計算されます。
