# 確率分布（Distributions）

## 全体像

確率分布（またはデータ分布）は、取り得るすべての結果に対して値がどのように散らばっているか（広がっているか）を記述するものです。

データセットに対して、以下の問いに答えます:

- どの値がよく現れるか（頻出するか）？
- 中心はどこにあるか？
- データの広がり（ばらつき）はどれくらい広いか？
- 分布は対称か、それとも歪んでいるか（歪度）？
- 異常値や外れ値（アウトライヤー）は存在するか？

## ヒストグラム (Histogram)

ヒストグラムは、連続する数値を **ビン (Bins / 区間)** と呼ばれる小範囲に分割し、各区間に観測値がいくつ含まれるかをカウント（度数集計）して棒グラフにしたものです。

```text
度数 (Frequency)
  8 |          ███
  6 |       ██████
  4 |    █████████
  2 | ███████████████
    +-------------------
      0  10  20  30  40
```

ヒストグラムを読み解く際は、以下の4つの要素に着目します:

- **形状 (Shape):** 対称か、左右どちらかに歪んでいるか、一様か？
- **中心 (Center):** 分布の中央値や平均値はどこにあるか？
- **広がり (Spread):** データはどれくらい広く分散しているか？
- **外れ値 (Outliers):** 他から極端に離れた異常値はあるか？

Python による可視化例:

```py
import matplotlib.pyplot as plt

values = [10, 12, 13, 15, 18, 21, 30, 50]

plt.hist(values, bins=5, edgecolor="black")
plt.xlabel("値")
plt.ylabel("度数")
plt.show()
```

## 正規分布 (Normal distribution)

正規分布（ガウス分布）は、中央を中心とした左右対称の釣鐘型（ベルカーブ）の分布です。

主な特性:

- 平均値、中央値、最頻値（モード）がすべて一致する。
- 中心の近くにある値が最も高頻度で出現する。
- 中心から離れるにつれて出現頻度が急速に低下する。
- 左右が完全に対称である。

正規分布は2つのパラメータで決定されます:

- 平均: $\mu$ （中心位置を決定）
- 標準偏差: $\sigma$ （広がりの幅を決定）

**経験則（68-95-99.7 ルール）:**

| 平均からの距離          | 含まれるデータの割合 |
| ----------------------- | -------------------: |
| 平均 $\pm 1\sigma$ 以内 |                  68% |
| 平均 $\pm 2\sigma$ 以内 |                  95% |
| 平均 $\pm 3\sigma$ 以内 |                99.7% |

## 一様分布 (Uniform distribution)

一様分布では、取り得るすべての値や等しい幅の区間がまったく同じ確率で発生します。

例えば、歪みのない6面体のサイコロを振ったときの出目は、各目（1, 2, 3, 4, 5, 6）が出る確率がすべて等しく $1/6$ であるため一様分布に従います。

$$
P(X=x)=\frac{1}{6},
\qquad x\in\{1,2,3,4,5,6\}
$$

## 二項分布 (Binomial distribution)

二項分布は、**独立した試行** を決まった回数だけ繰り返したときに、「成功」した回数をモデル化する確率分布です。

適用条件:

- 試行回数 $n$ が固定されている。
- 各試行の結果が「成功」または「失敗」の2通りしかない（ベルヌーイ試行）。
- 各試行における成功確率 $p$ が常に一定である。
- 各試行が互いに独立している。

$$
X\sim\operatorname{Binomial}(n,p)
$$

$k$ 回成功する確率は以下の公式で求まります:

$$
P(X=k)=\binom{n}{k}p^k(1-p)^{n-k}
$$

- $\binom{n}{k}$: $n$ 回中 $k$ 回成功する組み合わせの数
- $p^k$: $k$ 回成功する確率
- $(1-p)^{n-k}$: 残りの $(n-k)$ 回失敗する確率

### 例: 不良品検査

製品の不良率が 0.1（10%）の製造ラインにおいて、製品を 20個ランダムに検査したとき、不良品の個数は $n=20, p=0.1$ の二項分布に従います。

不良品がちょうど 3個見つかる確率の計算:

1. パラメータの確認: $n=20, p=0.1, k=3$
2. 二項分布の公式への代入:
   $$
   P(X=3)=\binom{20}{3}(0.1)^3(0.9)^{17}
   $$

組み合わせの計算:

$$
\binom{20}{3} = \frac{20!}{3!(20-3)!} = \frac{20 \times 19 \times 18}{3 \times 2 \times 1} = 1140
$$

確率の計算:

$$
P(X=3) = 1140 \times (0.1)^3 \times (0.9)^{17} \approx 1140 \times 0.001 \times 0.16677 \approx 0.1901 \quad (19.01\%)
$$

Python (SciPy) での計算:

```py
from scipy.stats import binom

n = 20
p = 0.1
k = 3  # 不良品の個数
probability = binom.pmf(k, n, p)
print(f"不良品が {k} 個見つかる確率: {probability:.4f}")
# 不良品が 3 個見つかる確率: 0.1901
```

## パーセンタイル（百分位数 / Percentiles）

パーセンタイルは、データを小さい順に並べたときに、特定の値以下にある観測データの割合（％）を示します。

例:

- **第25パーセンタイル:** 全データの 25% がその値以下にある。
- **第50パーセンタイル:** 全データの 50% がその値以下にある（**中央値** と一致）。
- **第90パーセンタイル:** 全データの 90% がその値以下にある（上位 10% の境界）。
- **第99パーセンタイル:** 全データの 99% がその値以下にある（上位 1% の境界 / レイテンシ評価などで多用）。

## クォンタイル（分位数 / Quantiles）

クォンタイルは、ソートされたデータを等しいサイズに分割する一般的な概念です。

- **四分位数 (Quartiles):** データを 4分割する（25%, 50%, 75%）。
- **十分位数 (Deciles):** データを 10分割する（10%, 20%, ..., 90%）。
- **百分位数 (Percentiles):** データを 100分割する。

| クォンタイル値 |       対応するパーセンタイル |
| -------------: | ---------------------------: |
|           0.25 |           第25パーセンタイル |
|           0.50 | 第50パーセンタイル（中央値） |
|           0.90 |           第90パーセンタイル |
|           0.99 |           第99パーセンタイル |

## パーセンタイル vs パーセンテージの違い

- **パーセンタイル (Percentile):** 分布の中での「位置（順位）」を示します。
- **パーセンテージ (Percentage):** 特定の条件を満たすデータの「割合」を示します。

例えば、「CPU 使用率が 90パーセンタイル以上」とは、稼働時間の 10% において CPU 使用率がその値を超えていることを意味します。
一方、「CPU 使用率が 90% 以上」とは、CPU の最大処理能力の 90% 以上を消費していることを意味します。

## しきい値設定へのパーセンタイルの活用

固定の絶対値しきい値が適切でない場合、パーセンタイルを用いることでデータの特性に応じた動的しきい値を設定できます。

```py
import numpy as np

values = np.array([10, 12, 13, 15, 18, 21, 30, 50])

print(np.percentile(values, 25))
# 12.75
print(np.percentile(values, 50))
# 16.5
print(np.percentile(values, 90))
# 36.0
print(np.quantile(values, 0.90))
# 36.0

# デフォルトでは、求めたいパーセンタイルが2つのデータ点の間にある場合、np.percentile は線形補間を行います。
i = (len(values) - 1) * 0.90
lower_index = int(np.floor(i))
upper_index = int(np.ceil(i))
lower_value = values[lower_index]
upper_value = values[upper_index]
print(f"下限インデックス: {lower_index}, 上限インデックス: {upper_index}")
print(f"下限値: {lower_value}, 上限値: {upper_value}")
# 下限インデックス: 6, 上限インデックス: 7
# 下限値: 30, 上限値: 50
interpolated_value = lower_value + (i - lower_index) * (upper_value - lower_value)
print(f"補間された第90パーセンタイル: {interpolated_value}")
# 補間された第90パーセンタイル: 36.0
```
