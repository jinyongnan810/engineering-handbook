# 相関と因果（Correlation vs causation）

## 1. 相関関係 (Correlation)

**相関関係** とは、2つの変数が一緒に連動して変化する傾向があることを意味します。

| 関係の種類                  | 意味                                        |
| --------------------------- | ------------------------------------------- |
| **正の相関 (Positive)**     | A が増加すると、B も増加する傾向がある      |
| **負の相関 (Negative)**     | A が増加すると、B は減少する傾向がある      |
| **無相関 (No correlation)** | A と B の間に明確な連動パターンが見られない |

例:

> 運動を頻繁に行う人ほど、体重が軽い傾向がある。

これは **相関関係** です。

しかし、これは自動的に以下を意味するわけでは**ありません**:

> 運動だけが体重を減らした直接の原因である。

食生活や年齢など、他の要因が関わっている可能性があります。

---

## 2. 因果関係 (Causation)

**因果関係** とは、一方が原因となって他方の結果を直接引き起こす関係を意味します。

例:

> 毒物を摂取すると、健康に重大な被害が生じる。

これは直接の生理的メカニズムが存在するため因果関係です。

しかし、現実世界の多くの現象において因果関係の証明は困難です。

例:

> コーヒーを飲む人ほど、仕事の生産性が高い。

考えられる解釈:

1. コーヒーが生産性を向上させている（因果関係）。
2. 生産性が高い人ほど、結果としてコーヒーを好んで飲む。
3. 第3の要因（職種、生活習慣、睡眠時間など）が両方に影響を与えている。
4. 単なる偶然のパターンである。

このように、相関関係は手がかり（ヒント）を与えてくれますが、因果の証明にはなりません。

---

## 3. 交絡因子 (Confounding variables)

**交絡因子（交絡変数）** とは、研究対象となっている両方の変数に影響を与えている隠れた第3の変数のことです。

古典的な例:

> 夏になると、アイスクリームの売上と水難事故の件数の両方が増加する。

ここから次のように結論づけるのは明白な誤りです:

> アイスクリームを食べると水難事故が起きる（因果の誤謬）。

真の交絡因子は **気温の上昇（暑い気候）** です。

暑い気候がアイスクリームの売上を伸ばし、同時に暑い気候によって水泳をする人が増えるため水難事故が増加します。

```text
気温の上昇（交絡因子）
   ├── アイスクリームの売上増加
   └── 水泳をする人が増える → 水難事故の増加
```

2つの変数は強く相関していますが、一方が他方を引き起こしているわけではありません。

---

## 4. 疑似相関 (Spurious correlation)

**疑似相関（見かけ上の相関）** とは、一見意味のある関係に見えるものの、実際には単なる偶然や無関係な外部要因によって生じている相関関係のことです。

例:

> 公開された映画の本数と、まったく無関係なある事故の発生率が、年月の経過とともにどちらも増加している。

これらは、人口増加、技術の進歩、記録体制の充実、あるいは単なる「時間の経過に伴う長期トレンド」によって両方が同時に右肩上がりになっているにすぎません。

疑似相関の典型的な原因:

```text
両方の変数が時間の経過とともに上昇傾向（トレンド）を持っている。
```

例:

```text
インターネットの利用率が上昇した。
平均住宅価格が上昇した。
```

これは「インターネットを使ったから住宅価格が上がった」ことを意味しません。経済成長、都市化、インフレ、人口動態などが共通の背景にあります。

---

## 5. 観察データの限界

**観察データ (Observational data)** とは、対象に介入せず、自然に起きた現象をそのまま記録・観察したデータです。

例:

> コーヒーを飲む習慣のある人と、飲まない人を比較する。

問題点: これら2つのグループは、コーヒーの有無以外にも多くの点で異なっています。

| 考えられる交絡因子 | なぜ重要か                                                 |
| ------------------ | ---------------------------------------------------------- |
| 年齢               | 年齢層によって生活習慣が大きく異なる                       |
| 職種               | 特定の職種（デスクワークなど）ほどコーヒーを飲む機会が多い |
| 睡眠習慣           | 睡眠不足の人ほど眠気覚ましにコーヒーを多飲する             |
| ストレスレベル     | ストレスがコーヒー摂取量と生産性の両方に影響する           |
| 収入               | 収入水準が生活習慣、健康状態、職場環境に影響する           |

したがって、観察データから言えるのは:

> 「両者の間には関連（相関）が見られる。」

ということであり、通常はこれだけで:

> 「A が B を引き起こした。」

と完全に証明することはできません。

---

## 6. 因果関係を証明するための強力な証拠

因果関係を主張するためには、相関関係以上のエビデンスが必要です:

| 証拠の種類                              | なぜ有効か                                                         |
| --------------------------------------- | ------------------------------------------------------------------ |
| **ランダム化比較試験 (RCT / ABテスト)** | 被験者を無作為に割り振ることで交絡因子を均等化・排除できる         |
| **前後比較 (Before / After)**           | 原因となる事象の後に結果の変化が起きているか（時間的先行性）を確認 |
| **用量反応関係 (Dose-response)**        | 原因の量を増やすほど、結果の大きさも比例して増大するか             |
| **妥当なメカニズム**                    | A が B を引き起こす物理的・生物学的・論理的な仕組みが説明できるか  |
| **再現性 (Repeated results)**           | 異なる環境や集団でも同じパターンが一貫して確認されるか             |
| **交絡因子の統制**                      | 年齢、収入、職種などの影響を統計的に補正・コントロールする         |

例:

> 被験者をランダムに2グループに分け、一方にカフェイン、他方にプラセボ（偽薬）を投与して比較した場合、カフェイン群のパフォーマンスが向上したならば、単にコーヒー愛好者を観察するよりもはるかに強力な因果の証拠になります。

## 7. 思考チェックリスト

「A と B が関連している」という主張に出会ったときは、以下の問いを確認します:

```text
1. 逆に B が A の原因ではないか？（逆の因果関係）
2. 第3の要因（交絡因子）が両方を引き起こしていないか？
3. 単に両方が時間とともに増加・減少しているだけではないか？
4. これはランダム化された実験か、それとも単なる観察データか？
5. 納得のいく具体的なメカニズムが存在するか？
6. 交絡因子を統制（補正）した後もその関係性は残るか？
```

例:

> 授業中にノートパソコンを使う学生ほど成績が低い。

考えられる複数の解釈:

```text
ノートパソコンの使用が集中力を削いでいる。
成績不振の学生ほどノートパソコンを授業に持ち込みがちである。
ノートパソコンを必須とする難関講義の成績が全体的に低い。
パソコンを使う学生ほど同時にマルチタスク（SNS等）をしてしまっている。
```

したがって、「ノートパソコンが成績低下の原因だ」と短絡的に結論づけるべきではありません。

より正確な表現:

> 「ノートパソコンの使用と成績低下には相関が見られるが、直接の因果関係があるかどうかを判断するには更なる検証が必要である。」

## 8. 実践演習

### 事例 1

> 高級なランニングシューズを持っている人ほど、走るタイムが速い。

考えられる交絡因子:

```text
体力・運動能力
トレーニング歴
収入
ランニングの頻度
競技への本気度・モチベーション
```

妥当な結論:

> 高価なシューズと走る速さには相関があるが、本気でトレーニングしている熱心なランナーほど高価なシューズを購入する傾向があるためと考えられる。

---

### 事例 2

> 警察官の数が多い都市ほど、犯罪発生件数が多い。

考えられる交絡因子:

```text
都市の人口規模
人口密度
元々の治安水準
観光客数
犯罪の認知・通報件数の多さ
```

妥当な結論:

> 警察官の増員は犯罪への対策（結果）として行われた可能性が高く、警察官が多いことが犯罪の原因ではない。

---

### 事例 3

> 睡眠時間が長い人ほど、記憶力テストのスコアが高い。

考えられる交絡因子:

```text
ストレスレベル
全体的な健康状態
年齢
労働時間・勤務形態
運動習慣
精神的健康
```

妥当な結論:

> 睡眠と記憶力には密接な関連があり因果メカニズムも妥当と考えられるが、観察データのみから因果を断定するには交絡因子のコントロールが必要である。
